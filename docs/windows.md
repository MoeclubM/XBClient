# Windows 客户端

Windows x64 采用原生 WinUI 3（.NET 9 自包含发布）与 `xbclient_ffi.dll` 共享商业/连接内核，无需安装运行时或浏览器内核。首次启动默认使用系统代理，已有用户保留保存的连接偏好。账号登录、订阅同步、协议支持和分流规则与共享 Neto / Aerion 内核一致；XBoard 与 PxBoard 的登录方式见 [构建文档](build.md)。

## 连接与权限

系统代理可使用普通用户权限。开启后，XBClient 启动本地混合端口（同时支持 HTTP、HTTPS CONNECT、WebSocket 与 SOCKS5），默认仅监听 `127.0.0.1`，可在设置中按需开启局域网共享。规则、全局与直连模式共用统一流量跟踪与策略组路由入口。

TUN 需要管理员权限。发布包内置 `wintun.dll` 与 `xbclient_ffi.dll`，普通权限启动后如需开启 TUN，可直接在连接页、设置页或系统托盘菜单点击「提权启用 TUN / 以管理员身份重启」一键完成提权切换。系统代理只接管遵循 Windows 代理设置的应用；TUN 用于接管全局网卡流量。

客户端采用单实例机制，重复启动会自动唤醒已在托盘运行的窗口。关闭主窗口默认最小化驻留系统托盘，托盘右键菜单支持快速连接断开、切换规则/全局/直连模式、切换节点、开关系统代理与 TUN、断开活跃会话、复制终端代理环境变量以及彻底退出。

## 网络设置恢复

首次接管系统代理时，客户端保存当前用户的手动代理、自动代理脚本、自动检测和连接设置。切换节点时保留这份原始设置；断开、退出或安装更新前先恢复，再停止本地代理和内核。停止 TUN 会等待其网卡与路由清理完成。

内核运行结束或系统注销关机时，客户端会自动恢复原始系统代理；若进程被强制终止，下次启动客户端或运行卸载程序时也会自动读取注册表备份 `HKCU\Software\XBClient\SystemProxy` 恢复代理并清理残留。

## 构建验证

Windows 与 Linux 安装包通过 GitHub Actions 构建。桌面检查使用真实 Aerion SOCKS 入口验证 HTTP 请求、HTTPS CONNECT 与隧道关闭；Windows 另验证多次接管后恢复原代理设置，并检查安装包内包含 TUN 驱动。该验证不替代真实账号授权、系统休眠和长时间运行检查。
