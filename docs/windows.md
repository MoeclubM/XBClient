# Windows 客户端

Windows x64 提供安装包和便携版。首次启动默认使用系统代理，已有用户保留保存的连接偏好。账号登录、订阅同步、协议支持和分流规则与共享 Aerion 内核一致；XBoard 与 PxBoard 的登录方式见 [构建文档](build.md)。

## 连接与权限

系统代理可使用普通用户权限。开启后，XBClient 启动仅监听 `127.0.0.1` 的 HTTP 代理，将 HTTP 请求、HTTPS CONNECT 和 WebSocket 升级连接交给当前会话的 SOCKS 入口，目标域名由代理连接解析。规则、全局与直连模式使用同一入口；不会向局域网开放代理端口。

TUN 需要以管理员身份运行。安装包携带 `wintun.dll`，放在 `resources/bin` 中，与内核程序相邻。普通权限启动后如需 TUN，请退出，再右键以管理员身份运行。系统代理只接管遵循 Windows 代理设置的应用；TUN 用于接管其他应用的网络流量。

选择节点、切换模式和连接设置会按顺序执行。退出账号先断开会话，再清除登录信息。关闭主窗口会留在托盘；从托盘退出才会停止客户端。

## 网络设置恢复

首次接管系统代理时，客户端保存当前用户的手动代理、自动代理脚本、自动检测和连接设置。切换节点时保留这份原始设置；断开、退出或安装更新前先恢复，再停止本地代理和内核。停止 TUN 会等待其网卡与路由清理完成。

内核进程异常退出或 TUN 运行结束时，客户端清除连接状态并显示错误；Windows 系统代理由主进程独立恢复。若整个客户端被强制结束，重新打开客户端会先恢复上次保存的代理设置。备份位于当前用户注册表 `Software\MoeclubM\XBClient\SystemProxy`，恢复成功后删除。

## 构建验证

Windows 与 Linux 安装包通过 GitHub Actions 构建。桌面检查使用真实 Aerion SOCKS 入口验证 HTTP 请求、HTTPS CONNECT 与隧道关闭；Windows 另验证多次接管后恢复原代理设置，并检查安装包内包含 TUN 驱动。该验证不替代真实账号授权、系统休眠和长时间运行检查。
